# 截图表格 → Excel 还原

## 适用
用户给一张表格图片，要求做成 Excel。核心不是"造表"，而是**忠实还原原表版式与数据**——列顺序、双层分组表头、每列数字格式都照搬。

## 流程

### 1. 放大识读（不要只看缩略图）
原图往往很小（如 1701×154，文字高仅 ~10px），直接 Read 必然误读数字。

```bash
# 需已安装 Pillow(pip install pillow)
PY="python"   # 任意已安装 Pillow 的 Python(在 PATH 中的即可)
"$PY" -c "
from PIL import Image
im=Image.open(r'<原图>'); W,H=im.size; print(im.size)
n=4
for i in range(n):
    x0=int(W*i/n); x1=int(W*(i+1)/n)
    c=im.crop((x0,0,x1,H)); c=c.resize((c.width*3,c.height*3), Image.LANCZOS)
    c.save(f'tmp_img/part{i}.png')
"
```
- 先横向切 4 块 3 倍 → 定位列边界与表头结构。
- 再按**列**纵向整条切（如 `(340,0,600,H)`）6~8 倍精读关键字段；单个单元格最多用 12~16 倍（更高倍数只是插值，不再增加信息）。
- 行边界靠裁不同 y 区间试出来（表格线在放大后会很明显）。

### 2. 处理"文字被截断"
原表列宽不足时有两种表现，判断方式不同：
- **左对齐溢出**：文字向右溢出显示，完整内容可见 → 照抄。
- **居中/右对齐溢出**（更常见）：两侧都溢出，左侧被相邻列盖住 → 看到的是**中间一段**。
  反推方法：列宽 W（约能放几个汉字）× 完整名长度 L，居中偏移 = (W−L)/2（负值=左侧被盖）。用可见片段的起点反解 L，再用**外部信息核实**（见下）。

### 3. 核实名称（关键一步）
被截断的几乎都是公司名/机构名。用 WebSearch 搜可见片段 + 关键词（"XX 深圳 有限公司 工商"），拿到**工商全称**再回填——原表的简称可能不完整（"深圳X" vs "深圳市X"、"有限公司" vs "有限责任公司"）。

同时把原图里被红笔/批注/高亮遮盖的单元格记录下来，**不要瞎猜**：填最可能的同批次值，并在该单元格加 openpyxl `Comment` 说明"原图被遮盖，已按 X 填，请核对"。

### 4. 生成 xlsx
用 openpyxl 直接写 xlsx，写完做重算校验（见第 5 步）。还原要点：
- 双层表头：一级分组行 + 二级子表头行，单列跨两行用 `merge_cells("A1:A2")`，分组用 `merge_cells("H1:K1")`；合并后**必须在左上角单元格**写值和样式（合并区其他格是 `MergedCell`，写入/加批注会报 read-only）。
- 合并区右上角的空白格要单独补底色+边框，否则出现白洞。
- 分组表头行若有子列未参与合并，`Autofilter` 范围从**二级表头行**开始（`A2:T6`）。
- 金额 `#,##0.00`、日期 `yyyy/m/d`、编码列 `@`；日期写 `datetime.date` 对象而非字符串。
- 可推导列（如"欠款金额 = 已履行金额 − 付款金额"）写成公式 `=IF(OR(L3="",P3=""),"",L3-P3)`，并在表头加批注说明口径。

### 5. 交付前
- `recalc.py` 必须 `status=success / total_errors=0`（openpyxl 写的公式没有缓存值，不重算在预览器里是空白）。
- 回读 `data_only=True` 逐行打印核对数字。
- 清理临时放大的图片目录。

## 提示
- 数字逐列核对，不要靠"大概看着像"：`40,000.00` / `40000` 在小图里极易看错。
- 原表序号可能是倒序的（266→0131号、267→0128号…），照原样保留，不要"顺手排序"。
